実行コードは統合版 `c5e6ac912`。GPUプロファイラーなし。5問完走、スワップアウト0、MTP採用352/560。

## RTX・MI50・転送の同時トレース

通常実行と同じ採用設定で別実行。Nsight SystemsのCUDA Graph単位トレースとrocprofv3を照合した実3位置275検証。トレースありの生成は50.21 tok/s、MTP採用354/553。RTX側のCUDA Graphは全体の実行区間で集計し、個別ノードの演算時間には分解していない。

| 本体検証中の活動（重複なし） | ms/検証 |
| --- | ---: |
| RTXのみ活動 | 13.053 |
| MI50のみ活動 | 10.232 |
| 両GPUが同時に活動 | 2.586 |

GPU活動の各行では、コピーが同時進行している場合がある。コピーのみのうち、観測したExpert tupleのH2Dは4.285 ms、D2Hは0.067 ms/検証。非活動6.730 msのうち、ホスト側の重み以外の受け渡し2.536 ms、Expert重み準備2.274 ms、グラフ投入1.379 msと区間が重なった。RTX本体の `cudaGraphLaunch` に重なる非活動は0.268 ms/検証。ノード単位の旧計測で出た3.167 msは主にプロファイラー負荷だった。
