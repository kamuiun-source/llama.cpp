# MI50 IQ3_XXSの位置間重み再利用

## 統合版の固定3幅ログ

2026-11-24の `codex/rocm-integrated-test`、`85e2ae78a` の保存トレースを使用。RTX 4070 Ti＋MI50、Qwen3.8 Flash Next UD-IQ3_XXS、単一バンク・直接DMA、CPU Expert自動配分導入前の固定5問。生成中の `phase=verify`、`verify_width=3` の281回だけを使用し、短くなった検証と通常デコードを除外した。

Expertのgate/upが1プレーン627,200 B（640行、1行10ブロック、1ブロック98 B）の21層を選び、MI50のrocprof報告のIQ3_XXS gate/up起動数5,901件と一致することを確認した。各検証・層で、3位置それぞれのtop 10に同じExpert IDが何回出たかを数えた。層や検証をまたぐ再利用は含めない。

| 同じExpertを使った位置数 | Expertグループ | グループ比率 |
| --- | ---: | ---: |
| 1位置 | 76,419 | 64.68% |
| 2位置 | 24,585 | 20.81% |
| 3位置 | 17,147 | 14.51% |
| 合計 | 118,151 | 100% |

複数位置のグループは41,732件（35.32%）。177,030選択のうち58,879件（33.26%）は同じ層・検証内の2回目以降の選択で、層実行あたり平均9.98件。設問別では21.75〜36.78%。同じIDを2回以上選んだグループ内の選択は100,611件（56.83%）。選択回数から求めた理論的な再利用機会で、HBM転送量や現行CPU Expert自動配分後の割合は未計測。

## Strataのレジスタ再利用の単体試作

`302422e6c` の統合版から `codex/rocm-iq3-strata-reuse` を作成。Strataのサブグループで行を担当し、圧縮重みのロードと復号を位置ごとの内積で再利用する考え方を単体で確認する。合成の重みと活性化を使い、共有数は実測で現れた混在パターンに合わせる。同一の入力とExpert IDで通常カーネルと照合し、ビット一致・カーネル時間・VGPR・LDSを比較する。[Strataの実装](https://github.com/Niko1221/Strata/blob/c234774038d1c9249cb33637d27b895d47b39786/engine/src/kernels/cuda/iq_kernels.cu#L1918-L1964)

試作ではwave64を16レーンずつに分け、各組が別の出力行を担当する。重みはVRAMから読み、復号したgate/upを1〜3位置にレジスタで使い回す。LDSにはテーブルとQ8_1入力を置く。各レーンは元のwave64の4レーンを受け持ち、元の加算・縮約順を再現する。

MI50単体、合成入力、MTPなし。2種類の混在は保存トレースのrequest 0、step 1、層25と17の選択を、同じIDに対する関係と順位を保って合成IDへ差し替えた。3つ目は30選択すべてが共有に参加する条件。各60試行・1試行64起動で通常版と試作の順を交互にした。

| Expertグループの構成（1・2・3位置） | 通常（µs） | 試作（µs） | 対応する試行の差（µs） |
| --- | ---: | ---: | ---: |
| 12・6・2 | 130.58 | 105.96 | −24.64 |
| 17・5・1 | 130.05 | 116.86 | −13.30 |
| 0・0・10 | 130.97 | 75.37 | −55.50 |

全3条件で各19,200出力がビット一致、非有限値0。LDSは両カーネル9,664 B。通常は63 VGPRと常駐上限5ワークグループ/CU、試作は209 VGPR、固定プライベート領域24 B/スレッド、常駐上限1。ワークグループ数は1,600から、各条件で800・920・400に減る。実測値はカーネルと起動形状を合わせた比較で、GPU側のグループ構築や転送は含まない。実モデル経路への組み込みは未実施。

単体のソースは [iq3-strata-reuse.hip](../scripts/iq3-strata-reuse.hip)。gfx906のビルド・実行とも終了コード0。[実行ログ](/home/t-saka/rocm-iq3-strata-register-reuse-20261126/run.log)

## 実モデルでの比較

同じ試作ブランチで、対応するMI50の固定3幅・IQ3_XXS gate/up＋SwiGLUをランタイム設定で切り替える。既定はOFF。CPU Expert自動配分で処理する位置、通常のExpert転送、非同期昇格と次層先読みの整合を保つ。実モデル側のルート表の作成・転送と融合カーネルを計測し、通常計測では同じビルド・CPU Expert自動配分ONで固定5問を比較する。出力、生成トークン、MTP採用数、生成速度を併記する。

### 通常速度

RTX 4070 Ti＋MI50、Qwen3.8 Flash Next UD-IQ3_XXS、固定3幅・単一バンク・直接DMA・CPU Expert自動配分ON・catch-up統合ON。同一サーバーでモードファイルをOFF→ONと変更し、各条件でウォームアップとスロットの消去を行った。5問の会話内はKVを再利用した。両条件とも5問がEOSで完走し、プロファイラーなし。生成速度は5問の生成トークン数の合計を生成時間の合計で割った。

| 指標 | OFF | ON |
| --- | ---: | ---: |
| 生成 tok/s | 57.36 | 59.91 |
| 生成トークン | 1,223 | 1,252 |
| 生成時間 | 21.321秒 | 20.899秒 |
| MTP採用 / 提案 | 679 / 1,080 | 699 / 1,100 |
| 第1候補の採用 | 394 | 403 |
| 第2候補の採用 | 285 | 296 |

速度は+4.44%。各問の生成速度はOFF→ONで50.86→56.90、55.75→56.36、54.57→58.46、62.82→65.34、65.92→63.31 tok/s。ウォームアップの8トークンは一致し、本試行の生成ID・本文は全5問で異なった。第1問の最初の差は61トークン目。全問とも日本語で回答を完結。第4問ではPythonコードが一致し、実行値は60.00 ms、27.00 ms、55.00%。説明文ではOFFが約60%、ONが約46%と回答し、両方に数値の誤りがあった。同じサーバーで各1回の比較であり、出力差や速度差を単独要因には帰属できない。[会話別結果](/home/t-saka/rocm-iq3-strata-model-ab-20261126/session-batch-01)

ON側のシャットダウン集計では、ウォームアップ込みで21対象層・11,613表（553回の3位置検証）。表作成1.955 ms、既存の非同期スロット表への転送発行10.198 ms（ともにホスト計時）、同期コピー0。追加転送は1,393,560 B、1表あたり120 B。表作成は平均0.00354 ms/検証、発行は0.01844 ms/検証。発行値は元の2,048 Bも含む呼び出し全体で、追加120 Bだけの転送費用とは別。

各5問の冒頭と末尾を挟む監視サンプルで、ホストのスワップアウトは両条件0ページ、スワップインはOFF 7,259、ON 3,085ページ。ホスト全体の値で、個々のリクエストへの帰属は未計測。

### MI50と本体検証の計時

別の同一サーバーOFF→ONでrocprofv3を使用した。各5問のリクエスト時刻とROCTxを照合し、ウォームアップを除いた実3位置検証の区間だけを計時した。照合したマーカーは4,368個で、ROCm時刻とホスト計時区間の差は最大190 ns。両条件とも全問が完走した。

| 指標 | OFF | ON |
| --- | ---: | ---: |
| 実3位置検証 | 559 | 527 |
| MI50 IQ3_XXS gate/up起動数 | 11,739 | 11,067 |
| IQ3_XXS gate/up（ms/検証） | 2.809 | 2.545 |
| 対応表の作成・転送を含む本体検証（ms/検証） | 35.970 | 33.981 |

IQ3_XXSカーネルは−0.265 ms/検証（−9.4%）。トレースにはコピーサイズと転送対象名がないため、スロット表のH2D実時間だけは他の転送と区別できなかった。表の実時間を含む比較は本体検証の行を参照。ゲート処理の差にホスト計測の発行時間を足し込むと、重複や元からあるスロット表の転送を二重に数える。ここでの全体差には出力・Expert選択の変動とプロファイラーの負荷も含まれる。[GPUトレース](/home/t-saka/rocm-iq3-strata-profile-ab-final-20261126)

### プロファイラーなしでONを3回再計測

別セッションの同一サーバーで、初回と同じバイナリ・採用設定を維持し、ONのまま独立した5問の会話を追加で3回実行した。各回の前にウォームアップとスロットの消去を行った。全15応答がEOSで完走、サーバー終了コード0。各回の5問を挟むホスト監視区間でスワップアウトは0ページ。スワップインは順に7,093・6,429・2,587ページ。

| 回 | 生成トークン | 生成時間（秒） | 生成 tok/s | MTP採用 / 提案 |
| --- | ---: | ---: | ---: | ---: |
| ON 1 | 1,222 | 20.819 | 58.70 | 683 / 1,074 |
| ON 2 | 1,205 | 20.236 | 59.55 | 668 / 1,072 |
| ON 3 | 1,118 | 19.121 | 58.47 | 609 / 1,012 |
| 3回合算 | 3,545 | 60.176 | 58.91 | 1,960 / 3,158 |

3回とも最初のA/BのOFF 57.36 tok/sを上回った。合算で+2.70%。追加3回はいずれもOFFと全5問の生成IDが異なった。追加計測はONのみ、OFFの値は初回の別セッションから使用した。試作の既定はOFF。[ONの3回分の実行ログ](/home/t-saka/rocm-iq3-strata-on-repeat-20261126/session-batch-01)
