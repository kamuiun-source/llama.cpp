# 固定3幅のMI50単一バンクで仮置き枠のLRUを比較

対象は固定3幅、動的常駐、tuple DMA、単一バンクと単一スケジューラコピー。従来どおり空き枠を優先する。満杯のときは既存の置換可能条件を満たす所有Expertから、`packed_last_used` が最小の枠を選ぶ。同時刻は既存の枠順を使う。選択されたExpertを保護し、昇格、先読み、枠数と転送の寿命管理は共通。

既存の `LLAMA_EXPERT_OUTPUT_MODE_FILE` に `SCRATCH_LRU=off` または `SCRATCH_LRU=on` を追加する。省略時はOFF。全スロットが空いて次の要求を始める時点で読み込む。プロンプトキャッシュと枠の内容はモード変更だけでは消去しない。実験の各アームは同じ起動状態とウォームアップでそろえる。

明示的なOFF/ON指定時、単一スロットの応答ごとに `scratch_lru: phase=target_verify` を出力する。`demand_h2d_tuples` と `demand_h2d_bytes` は、ターゲット検証中にRAMからMI50へ発行した通常のtuple転送の実数とパディング込みバイト数。先読みH2D、VRAM内D2D、書き戻し、プリフィルを含まない。`applied` は満杯時にLRUを使った回数、`changed` は従来の先頭候補と異なる枠を選んだ回数。カウンタ取得は検証の計測区間外で行う。

固定5問の各問で転送件数・バイト数、実行時間、MTP採用数、生成IDと出力を比較する。
