# 対話速度比較用の固定プロンプト

## 実行ルール

- 毎回、新しい会話から開始する。
- 以下の5つを順番に送り、途中で履歴を消さない。
- コードブロック内の文章を変更せずに送る。見出しは送らない。
- 各回答の完了を待ってから次の文章を送る。
- 生成上限で回答が途中終了しても、続きを要求せず次の番号へ進む。
- 比較する際はモデル、コンテキスト長、生成上限、サンプリング設定を揃える。変更する最適化設定とバイナリの版を記録する。
- 通常速度測定と詳細計測は別の新しい会話で実施する。
- 生ログはGitに追加せず、`G:\AI\llama-hetero-moe-local\logs` に保存する。
- コンテキスト上限による履歴切り詰め・シフトが発生した場合は記録し、未発生の測定と混同しない。

## 1. 説明

```text
家庭で使うWi-Fiが夜だけ遅くなる原因を、ネットワークに詳しくない人向けに説明してください。主な原因を3つ挙げ、それぞれ理由を説明してください。日本語で400字程度、表は使わないでください。
```

## 2. 条件追加・切り分け

```text
追加情報です。有線接続のパソコンは夜でも速く、Wi-Fi接続のスマートフォンだけ遅くなります。ルーターは隣の部屋にあります。この条件から原因の優先順位を見直し、確認手順を3段階で示してください。日本語で400字程度、表は使わないでください。
```

## 3. 計画

```text
ここまでの話を踏まえ、機器を買い替えずに今夜30分で試せる改善計画を作ってください。各作業の所要時間と、改善したか判断する方法も含めてください。日本語で400字程度、表は使わないでください。
```

## 4. コード生成

```text
改善前後を比較するため、Pythonの標準ライブラリだけで応答時間の平均値を計算したいです。改善前は[42, 55, 38, 120, 45]、改善後は[25, 28, 24, 31, 27]で、単位はミリ秒です。各平均値と改善率を表示する短いコードを書いてください。改善率は「改善前の平均－改善後の平均」を改善前の平均で割った百分率とし、説明は200字以内にしてください。
```

## 5. 履歴の要約

```text
この会話を家族に共有するために要約してください。「分かっている状況」「優先して疑う原因」「今夜試すこと」「改善の確認方法」の4項目にまとめてください。まだ実行していない作業を実行済みと書かず、コードで使った数値も実測結果とは扱わないでください。日本語で400字程度、コードと表は使わないでください。
```
